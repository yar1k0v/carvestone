# Carvestone

Rust in `crates/`, web UI in `web/`. Tasks and design live in Stone: `target/debug/stone`. If missing, run `cargo build --bin stone`.

1. Load the `lead` skill first. You are the Lead.
2. Send every change through the crew, even a small one.
3. Follow `.claude/rules/crew.md`. Project details: `docs/crew-profile` in Stone.

Setup for a new machine: `docs/contributing-with-claude.md`. Put personal rules in `CLAUDE.local.md` and personal settings in `.claude/settings.local.json`. Git ignores both.
