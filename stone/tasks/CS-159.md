## Plan

Blind rule: never open `crates/engine/tests/it/import*.rs`, `crates/cli/tests/it/import.rs`, `bench/import/**`, `crates/engine/tests/golden/**` or the inline `mod tests` in `crates/engine/src/import/`. Work from the source, the docs MCP libraries `backlog.md` and `backlog.md-repo`, `stone get plans/m7-importers` and the invariants below.

No source change: a real bug found here goes under `## Notes`, and you stop.

1. Add `mod backlog;` to `crates/engine/tests/it/imports/mod.rs`, and create `crates/engine/tests/it/imports/backlog.rs`. Test through `import::backlog::plan_backlog` for mapping and `import::import_backlog` for runs.
2. Write a fixture project in `crates/engine/tests/fixtures/imports/backlog/input/`, in Backlog.md format: tasks, a subtask, a draft, a milestone, a decision and a doc.
3. Write `crates/engine/tests/fixtures/imports/backlog/expected/` by hand from the Backlog.md format and `import/backlog.rs#SECTION_MAP`. Never generate these files by running the importer. Add one test that compares the plan to this folder and to the expected notes.
4. Add table cases for field mapping: each task status; labels; every `SECTION_MAP` row; `DECISION_SECTIONS` order and a section kept after them; ticked criteria stay ticked; unknown keys are kept; a non-ISO date is noted; a CRLF source comes out LF.
5. Add table cases for ids: subtask numbers are stable and carry a parent link; drafts number after the highest task; the prefix comes from `ImportOpts`, then the backlog config, then the repo config; config beside the folder is read; custom-prefix and `task-` files both read.
6. Add table cases for references: task, doc, decision and milestone ids become links; plain text that only looks like an id stays text.
7. Add one case per stop: unknown dependency, bad task status, bad decision status, draft status without the vocabulary. Assert that the error names the next step and that nothing is written.
8. For each invariant group, break the code on purpose, confirm a test fails, restore the code, and record it under `## Notes`. Confirm with `git diff crates/engine/src` that nothing stays changed.

Seams, all test choice add (rework from scratch, ADR-15). The expected folder catches format drift across a whole project, and misses single-field branches the fixture lacks. Table cases catch each branch, and miss interactions between fields. Stop cases catch partial writes on bad input, and miss wording quality.
