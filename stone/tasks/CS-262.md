## Description

A library crate shows no entry point, so `stone brief`, `code entries`, `code explain` and `map` say "none found" for a component made only of libraries, such as the engine. A brief also prints a "no outline" line for every path that is not code, such as a doc. After this task the crate root `src/lib.rs` of a Rust library is an entry of kind `library`, and the brief leaves out a path that exists but is not code.
