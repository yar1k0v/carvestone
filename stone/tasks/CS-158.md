## Description

First part of the from-scratch suite (ADR-15): the shared apply step, the table parser and the CLI wiring. It lives beside the old tests until the proof task deletes them.

- [ ] `cargo test -p carvestone-cli --test it imports::` → `N passed`, N above 0, 0 failed

## Plan

Blind rule: never open `crates/engine/tests/it/import*.rs`, `crates/cli/tests/it/import.rs`, `bench/import/**`, `crates/engine/tests/golden/**` or the inline `mod tests` in `crates/engine/src/import/`. Work from the source, `stone get plans/m7-importers` and the invariants below. `crates/engine/tests/it/common` may be used.

No source change: a real bug found here goes under `## Notes`, and you stop. Line numbers in `crates/engine/src/import/` must stay fixed until the proof task, because the old and new mutant lists are compared by line.

1. Add `mod imports;` to `crates/engine/tests/it/main.rs`, and create `crates/engine/tests/it/imports/mod.rs` with `mod apply;` and `mod table;`.
2. Write `crates/engine/tests/it/imports/apply.rs` through `import::import_backlog`, with small sources built in a `common::Tmp`. Invariants: importing twice gives no diff; one source change rewrites one file; a target edited in stone stays and reports `Skipped`; a missing state file leaves a differing target alone; a state file in the older bare-hash form still guards edits; a dry run writes nothing and does not wait for the lock; a target whose source went away is listed in `gone` and stays on disk; two importers do not report each other's targets; concurrent imports end equal to one import. Also cover `ImportReport::summary` and `ImportReport::count`.
3. Write `crates/engine/tests/it/imports/table.rs` through `import::table::parse_table`, as one table of cases. Invariants: header and separator rows drop; fenced tables are skipped; a table without a separator keeps its rows; an escaped pipe stays inside its cell; line numbers are correct.
4. Add `mod imports;` to `crates/cli/tests/it/main.rs`, and write `crates/cli/tests/it/imports.rs`: one smoke test per import command, with one report line asserted. CLI wiring only, no mapping checks.
5. For each invariant, break the code on purpose, confirm the test fails, restore the code, and record it under `## Notes`. Confirm with `git diff crates/engine/src` that nothing stays changed.

Seams, all test choice add (rework from scratch, ADR-15). Apply catches lost edits and non-idempotent writes, and misses mapping errors. Table catches cell splitting errors, and misses how importers use the rows. CLI catches broken argument wiring, and misses engine behavior.

Expected values are literals written by hand from the rules above, never copied from importer output.
