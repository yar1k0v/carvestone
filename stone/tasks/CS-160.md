## Plan

Blind rule: never open `crates/engine/tests/it/import*.rs`, `crates/cli/tests/it/import.rs`, `bench/import/**`, `crates/engine/tests/golden/**` or the inline `mod tests` in `crates/engine/src/import/`. Work from the source, the docs MCP libraries `groma.md` and `groma.md-repo`, `stone get plans/m7-importers` and the invariants below.

No source change: a real bug found here goes under `## Notes`, and you stop.

1. Add `mod groma;` to `crates/engine/tests/it/imports/mod.rs`, and create `crates/engine/tests/it/imports/groma.rs`. Test through `import::groma::plan_groma` for mapping and `import::import_groma` for runs.
2. Write a fixture bundle in `crates/engine/tests/fixtures/imports/groma/input/`, in Groma format: a system, a container, a component, a person, an external system, a flow and a draft.
3. Write `crates/engine/tests/fixtures/imports/groma/expected/` by hand from the Groma format. Never generate these files by running the importer. Add one test that compares the plan to this folder, and one that imports the bundle and asserts `common::Tmp::check` returns no problems.
4. Add table cases for elements: containers nest under their system; a person and an external system are tagged; draft status maps; reserved files and drafts are skipped; flow and draft sections stay verbatim.
5. Add table cases for identity across runs: a first import slugs from the title; a renamed element keeps its file; a removed element is gone; a second run on another date gives no diff.
6. Add table cases for link rewriting, through `plan_groma` (`Linker` is private): kept links name the imported documents; a link into a dropped section points at the page.
7. Add table cases for relations: `import::groma_relations::code_globs` sorts and dedupes. The rest go through `plan_groma`, because `join` and `clamp` are private: a row becomes a uses link and a bullet; HTTP and queue rows tag their bullet; rows to one target make one bullet; a file link resolves through its owner; a file nobody owns becomes a note; a row to the element itself is no use; backslashes normalise; `join` and `clamp` stay inside the bundle.
8. Add one case per stop: duplicate slug, missing parent, unknown relation target. Assert that the error names the line and that nothing is written.
9. For each invariant group, break the code on purpose, confirm a test fails, restore the code, and record it under `## Notes`. Confirm with `git diff crates/engine/src` that nothing stays changed.

Seams, all test choice add (rework from scratch, ADR-15). The expected folder catches format drift across a bundle, and misses branches the fixture lacks. Table cases catch each branch, and miss interactions. Identity cases catch files that move between runs, and miss first-run mapping. Stop cases catch partial writes on bad input, and miss wording quality.
