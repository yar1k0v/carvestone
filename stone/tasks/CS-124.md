## Description

Found by the Dart trial (CS-122). mobile/lib/shared/widgets/app_drawer.dart declares void go(String route) { ...; context.push(route); } and calls go("/profile"), go("/commands"), go("/scan") from the drawer rows. The push takes a variable so nothing links, and the helper calls are not recognised, so /commands and /scan show no navigating code. Idea: a function in the same file whose body passes a parameter straight to context.go/push is a navigation helper; its calls with a literal path become opens sites. Repro: stone code uses /scan lists the screen only.
