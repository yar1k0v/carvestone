## Description

`stone code find`, `code uses` and every command on the same resolver (`impact`, `path`, `outline`, `symbol`) match a `Type::method` tail with its exact letter case. Today the tail uses SQLite `LIKE`, which ignores ASCII case, so `code find world::new` lists `resolve::World::new`, and `World::new` is ambiguous when a module `world` also holds a `new`. Prefix matching in `code find` keeps its current rule; only the tail changes.

The full checks are deferred: the owner runs them once at the end of the session.
