## Description

Part of CS-99. dio and package:http calls in Flutter code become inferred requests links to the controller action with the same verb and route, so a mobile app shows as a connected service. See batch B3 in .planning/v1/m14.md.

## Acceptance criteria

- [x] _dio.get<T>('/api/x'), dio.post, put, delete, patch, with a path string or an interpolated string, give an inferred requests link to the matching controller action.
- [x] package:http calls with Uri.parse and a path or a base-URL variable link the same way.
- [x] A path built from a variable only, or a concatenation, links nothing and raises no error.
- [x] A call in a test file or generated file links nothing.
