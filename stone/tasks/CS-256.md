1. `crates/engine/src/why.rs#why`, the commit block. Move everything from `let mut commits = Vec::new();` to the end of the `for sha in &shas` loop into `fn commits_named(conn: &Connection, dir: &str, shas: &[String], uncommitted: bool) -> Result<(Vec<CommitRef>, BTreeMap<String, (String, BTreeSet<String>)>), EngineError>` (new), below `why`. `dir` is the value the loop passes to `params!` today (`one.dir()`): borrow it if `dir()` returns an owned `String`. Move the comment `ref id -> (trailer kind, commits that name it)` into the doc comment. `why` calls it as `let (commits, named) = commits_named(conn, .., &shas, uncommitted)?;`.
2. `crates/engine/src/why.rs#why`, the trailer lists. Move everything from `let mut lists = Lists::default();` to the end of the `for list in [..]` sort into `fn trailer_lists<'a>(snapshot: &'a Snapshot, named: BTreeMap<String, (String, BTreeSet<String>)>) -> (Lists, Vec<&'a Entry>)` (new), below `commits_named`. `why` calls it as `let (mut lists, mut task_entries) = trailer_lists(&snapshot, named);`. Doc comment: a ref the store knows goes to the list of its item type, and an unknown one goes to the list its trailer kind names.
3. `crates/engine/src/precedents.rs#precedents`, the ranking. Move the block from `let mut ranked` to the end of `ranked.sort_by(..)` into `fn rank(snapshot: &Snapshot, elements: &[Element], roles: &mut Roles<'_>, profile: &Profile, by_words: bool, words: &BTreeSet<String>, finished: Vec<(&Entry, Vec<(char, String)>)>) -> Result<Vec<Precedent>, EngineError>` (new), below `precedents`. Keep `Element` as the type `profile_of` already takes. It sorts by today's key, then returns `ranked.into_iter().map(|(_, _, _, p)| p).collect()`. Doc comment: the finished tasks that share points (or title words, with `by_words`) with the profile, best first. `precedents` then reads `let mut hits = rank(&snapshot, &elements, &mut roles, &profile, by_words, &words, finished)?;`. The `limit`, `omitted` and `split_off` lines stay in `precedents`, and `omitted` becomes `hits.len().saturating_sub(limit)`, read before `split_off`.
4. `crates/engine/src/tiers.rs#fit`, the share loop (rule R5). Move the block from `let mut order` to the end of the `for (handled, &at)` loop into `fn share_room(parts: &[Part], room: usize) -> Vec<usize>` (new), below `fit`. It starts `kept` from every part's full line count, as `whole` does today, and returns `kept`. Doc comment: R5 in one sentence (the optional parts, smallest first, each keep the longest prefix that fits an equal share of what is left). `fit` reads `let kept = share_room(parts, room);`, and `room` no longer needs `mut` there.
5. `crates/engine/src/tiers.rs#fit`, the cut sizes. The `left_out` vector becomes `parts.iter().zip(&kept).filter_map(|(part, keep)| left_out(&part.name, &part.lines[*keep..])).collect()`. `left_out` gives `None` for an empty slice and the same `lines` and `tokens` as the code it replaces.
6. After `cargo build --bin stone`, run the acceptance commands, then the full checks.
