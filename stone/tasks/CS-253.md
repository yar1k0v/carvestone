1. `crates/engine/src/root_file.rs` (new), declared as `mod root_file;` in `crates/engine/src/lib.rs` (private, after the `pub mod` line of `session_hook`). It holds one method, `impl Repo { pub(crate) fn rewrite_root_file(&self, path: &std::path::Path, label: &str, edit: impl FnOnce(&str) -> Result<String, EngineError>) -> Result<bool, EngineError> }`. The body is the shared flow of `crates/engine/src/session_hook.rs#Repo::write_session_hook`, in this order: take `self.store.lock()?`. Read `path`: a missing file is an empty text, bytes that are not UTF-8 give `EngineError::Invalid(format!("{label} is not valid UTF-8; nothing was written"))`, and another read error gives `EngineError::Invalid(format!("cannot read {label}: {e}"))`. Then call `edit(&text)?`, and set `changed = next != text`. When changed, run `create_dir_all` on the parent folder with the error text that `write_session_hook` has today, then `write_atomic(path, &next)?`. Drop the lock after the write, keeping the comment `Held to here so two writers never replace the file from the same stale read.`, and return `changed`. Doc comment: why one flow (the lock, the re-read and the minimal write rule hold the same way for every file the user owns).
2. `crates/engine/src/session_hook.rs#Repo::write_session_hook`: the body becomes `let path = self.store.layout.root.join(SETTINGS);`, then `rewrite_root_file(&path, SETTINGS, |text| apply(text).map_err(..))` with the same `map_err` message as today, then the `SessionHook { file: SETTINGS.to_string(), changed }`. Remove the `write_atomic` import when it is unused.
3. `crates/engine/src/agent_block.rs#Repo::write_agent_block`: keep the `target` and `file` lines. Then `rewrite_root_file(&path, &file, |text| apply(text).map_err(..))` with the same `map_err` message as today (`{file} has a broken stone block: {why}; fix the markers by hand`), then `AgentBlock { file, changed }`. `create_dir_all` on the repository root is a no-op, so the behavior does not change. Remove the `write_atomic` import when it is unused.
