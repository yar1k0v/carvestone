0. Baseline: run `cargo test -p carvestone-engine --test features search::`, `... history::` and `... tiers::`, and `cargo test -p carvestone-cli --test output_cost`, and write each `N passed` under `## Notes`. If any fails, stop and report.
1. One token rule. `crates/engine/src/search.rs#Hit::cost` returns `tiers::tokens(&self.line())`. `crates/engine/src/precedents.rs#Precedents::cost` and `crates/engine/src/why.rs#Why::cost` return `self.lines().iter().map(|l| tiers::tokens(l)).sum()`. Keep the per-line sum: a cost over the whole joined text would give other numbers and move the budget cut.
2. No front inserts. In `crates/engine/src/precedents.rs#Precedents::fit` and `crates/engine/src/why.rs#Why::fit`, `dropped.insert(0, ..)` becomes `dropped.push(..)`. `tiers::left_out` counts lines and the tokens of the lines joined by `"\n"`, and neither depends on the order. Change the doc comment of `Precedents::fit` (`in rank order`) and the comment in `Why::fit` (`the last one dropped first`) so they no longer state an order.
3. Two plain steps in `crates/engine/src/search.rs#search`. Add `fn built(item: Found) -> Hit` (new) below `search`, holding today's `match item` (a section hit gets `snippet(&c.title, &c.text)`). The hit loop becomes: `let mut rest = ordered.into_iter().map(built);`. Then `for hit in rest.by_ref()`, with the same stop test as today minus `stopped`. On a stop, push `hit.line()` into `dropped` and `break`. Otherwise add the cost and push the hit. After the loop, `dropped.extend(rest.map(|hit| hit.line()));`. Remove `stopped`. Keep the comment that snippets cost no query.
4. One sum rule. `crates/engine/src/tiers.rs#LeftOut` gets `pub fn with_more(left: Option<&LeftOut>, name: &str, more: &[String]) -> LeftOut` (new, an associated function). It returns `lines` = `left` lines (0 when `None`) + `more.len()`, and `tokens` = `left` tokens (0 when `None`) + `tokens(&more.join("\n"))`. Doc comment: each part is counted on its own and the counts are added, as `render_search` does today. `crates/cli/src/main.rs#render_search` builds `left` with `tiers::LeftOut::with_more(result.left_out.as_ref(), "hits", &lines[kept..])`, and its comment about merged lines stays.
