## Description

`stone brief` takes any item id, not only a task. For a doc, decision, plan or architecture item it prints, in one answer: the item, what it links to, what links to it (tasks, plans, decisions), the entry points of its components and up to 5 finished tasks on those components. Each line marks a stale item. An agent asking about a feature (a BRD or feature doc) gets the docs, architecture, code entry points and done work without 4 separate commands. A task brief stays as it is.
