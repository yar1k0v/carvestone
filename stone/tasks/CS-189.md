## Plan

1. `web/src/components/search/hits.ts`: add `HitGroup { name: string; hits: ShownHit[] }` and `ShownHit { hit: Hit; title: string; sub: string }`. Add `groupHits(hits: Hit[], rows: ListRow[], docs: DocRow[]): HitGroup[]`, in the order Feature, Tasks, Docs, System, Code, leaving out empty groups and keeping the answer's order inside a group. A `doc` whose `DocRow.group` is `feature` is Feature. `task` is Tasks. `doc`, `decision`, `plan`, `milestone` and `reference` are Docs. `system`, `container` and `component` are System. Anything else is Code.
2. Same file: `title` is the row's title, else the id. For Code it is the last part of `hit.id` after `::`, `.` or `/`. `sub`: a task gives `<short> · <status>`, a doc gives `chipText`, a decision, plan or milestone gives its `short` and status, System gives the kind, and Code gives `hit.path`. `chipText` is in `web/src/components/docs/library.ts`.
3. Add `useGroupedHits(hits)` to `web/src/components/search/useSearch.ts`, reading `useItemRows` from `web/src/components/markdown/useResolver.ts` and `useDocRows` from `web/src/components/docs/useDocs.ts`, with `useMemo`. Rows still loading give ids as titles and no failure.
4. `web/src/components/search/SearchHits.tsx`: takes `groups: HitGroup[]`, `query`, `active` and `compact?: boolean`. Each group is an `h2` at 12px weight 600, then its rows: title at weight 550, `sub` at 13px muted. `active` counts across groups in reading order. Without `compact`, the highlighted snippet stays as a third line. `KIND_ICON` goes, as the board has no icons. The "No results" sentence stays.
5. `web/src/components/search/CommandPalette.tsx#Palette`: Arrow and Enter use the flat order of `useGroupedHits`, so Enter opens the row that shows as active. Pass `compact`. The footer reads "Enter to open · Esc to close" on the left, or the truncated sentence when `result.truncated`, with All results on the right. `DialogContent` keeps its size up to 720px.
6. `web/src/components/search/SearchPage.tsx`: pass groups from `useGroupedHits`.
7. Test choice: patch `web/src/components/search/search.test.tsx`. Add `groups_hits_with_titles_product_first`, a table for `groupHits` with literal rows: a feature doc lands before a task, a task reads `CS-1 · todo`, a symbol `orders::Cart.total` reads `total`, an unknown id keeps its id. Add a palette case where ArrowDown then Enter opens the second row in shown order, not in answer order. Patch `hit_opens_section` and `symbol_hit_opens_its_class_page` for the new names. Catches Enter opening the wrong row. Misses the look, which step 8 covers.
8. Compare with the Search board at 1440 and 390 wide, in light and dark, on this repo's real store, using the `playwright-cli` skill, with a word that hits tasks, docs and code. Run `pnpm --dir web build` and `cargo build --features ui`, then in the Bash tool, background, `timeout 300 target/debug/stone.exe serve --no-watch --port 4748`. Let it end before you finish.
