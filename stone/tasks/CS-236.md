## Description

Stone keeps one line per item in `stone/index.md`: a markdown link with the item's description (OKF v0.2 section 8). Every command that writes an item updates that line under the same lock, `stone index` writes the full index for an existing store, and `stone check` warns when the index is out of date. For OKF readers and for agents that read the index first.

## Plan

Format (decided, do not change):

- One line per item: `- [<text>](<id>.md)` and, when the item has a description, ` - <description>`. `<id>.md` is the path from `stone/`, such as `tasks/CS-1.md` or `arch/acme/api.md`.
- `<text>`: `<label>: <title>` for a numbered item (`CS-1: First`, `M-2: …`, `ADR-3: …`), `<title>` for the others. No title: the last segment of the id. `[` and `]` in the title become `(` and `)`.
- `<description>`: the `description` field; when empty, `crates/engine/src/docs_list.rs#summary_of`; when that is `None`, the line ends after the link. Runs of whitespace become one space.
- Sections are level-1 headings, in this order: `# Docs` (`docs/`), `# Architecture` (`arch/`), `# Decisions` (`decisions/`), `# Plans` (`plans/`), `# Milestones` (`milestones/`), `# Tasks` (`tasks/`), `# References` (`refs/`).
- Order in a section: numbered items by number, the others by id as bytes.
- An item's line is the first line of the file whose first link (`carvestone_core::links`) has the target `<id>.md`, in any section. Every other line of the file is never changed.
- New text uses the line ending of the index (`carvestone_core::eol`).

Worked example, a new store after `new doc --title Guide --slug guide --set "description=How to install."` and then a first write of a task `CS-2` titled `Bare` with an empty body:

```
---
okf_version: "0.2"
---

# Docs

- [Guide](docs/guide.md) - How to install.

# Tasks

- [CS-2: Bare](tasks/CS-2.md)
```

5. Same file: `pub(crate) fn put(index: &str, scheme: &IdScheme, id: &ItemId, item: &Item) -> String`. Scan the whole file text with `carvestone_core::links(index, 1)` and `carvestone_core::sections(index, 1)`; write no other parser.
   - The item has a line: replace that line's text with `line_of`, keep its line ending.
   - No line, its section exists: insert the line before the first item line of the section that sorts after it; if none sorts after, directly after the last item line of the section; if the section has no item line, after the last non-blank line of the section, with one blank line between a heading and the line.
