1. `crates/engine/src/edit.rs#Edit`: add `verify: Option<String>` (the actor). In `crates/engine/src/edit.rs#Repo::edit_if_match`, count it in the "nothing to change" guard and add `--verify` to that message.
2. Same fn, inside the `update_if` closure: parse the actor with `crates/core/src/item.rs#Actor` (`by.parse::<Actor>()`). On error return `EngineError::Invalid` with the text `cannot stamp as `<by>`: <e>; pass --by human:<id>, process:<id> or a producer name such as claude-code`. Then append `stamp_value(&by, &now())` (`crates/engine/src/create.rs#stamp_value`, `#now`) to `verified`: no field gives a one-entry list, a single map becomes a list of the old map plus the new one, a list gets the new entry at the end. Other types return `EngineError::Invalid`: `<id> is a <type>; only docs, references and architecture items take a verified stamp`.
