## Description

Part of CS-99. Read Dart files with tree-sitter into the code index so stone code find and outline work on a Flutter repo: classes, mixins, enums, extensions, extension types, functions, methods, constructors, fields. The grammar crate is confirmed against tree-sitter 0.26 first. pubspec.yaml is a project file (name, dependencies).
