## Description

From the Freightline trials (point 4). Links found by convention and marked inferred, like the framework links of CS-108: a setting from where it is set (environment variable in a Kubernetes ConfigMap or Helm values, appsettings.json key) to the code that reads it (IConfiguration, Environment.GetEnvironmentVariable, os.environ, process.env); an EF entity to its table (DbSet, [Table], ToTable) and to the migrations that create or change it. Done when stone code uses <setting> lists where it is set and who reads it, and stone code uses <entity> lists its table and migrations.
