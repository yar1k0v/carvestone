## Description

With named `code_roots`, `stone check` needs an owner for every tracked file under them, so a project with art, config or docs beside its code gets one `owner` problem per such file (205 in games/crawl-away). Under any root, only files Stone reads as code now need an owner, as CS-183 already does for a whole-repo root. `stone scan` does not change.
