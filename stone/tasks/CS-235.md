## Description

OKF v0.2 section 5 asks for ISO 8601 timestamps with an explicit UTC offset. This task is the reading side: every reader accepts a plain `YYYY-MM-DD` and the full form `YYYY-MM-DDThh:mm:ss+00:00`, the date rule refuses a broken time or a missing offset, and the CLI and the web UI show the day only. Stone still writes plain dates after this task; the writers change in the follow-up task that depends on this one. Existing plain dates stay, and there is no migrate command.

1. In `crates/engine/src/check_fields.rs`, add a private `fn is_time(rest: &[u8]) -> bool`.
