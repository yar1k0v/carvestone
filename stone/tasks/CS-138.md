## Description

Third build step of ADR-13. A doc marked lld that names a start point as path#Symbol, or a diagram that names a file or symbol, is checked against the code index. stone check warns when the file or symbol is gone and says which doc names it. Builds on the drift both ways of CS-97.

## Acceptance criteria

- [x] stone check warns when a doc marked lld names a start point the code no longer has, and names the doc
- [x] stone check warns the same for a file or symbol named in a C4 diagram box
- [x] A clean store gives no new warning
- [x] cargo test --workspace and cargo clippy --workspace --all-targets -- -D warnings

## Outcome

stone check now warns, under the rule names flow and diagram-code, when a doc marked lld names a file or symbol (in its entry list or as a path#Symbol code span outside fences) that the code index no longer holds, and when a path#Symbol span in the box text of a C4 diagram in any doc does the same. Each warning names the doc and the missing target. A repo with no code index, a span that points at an existing non-code file such as Cargo.toml, and a clean store give no warning. The fmt check, clippy, the full workspace tests and stone check pass; stone check shows only the three warnings it showed before.
