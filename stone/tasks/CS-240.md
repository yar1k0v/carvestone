## Description

Follow-up of CS-233. The ready check gates `stone task move <id> in-progress` only. `stone edit <id> --set status=in-progress` and the server PATCH of an item (the web UI) change the status through `crates/engine/src/edit.rs#edit_if_match` and skip the check. This task gates that path too: `--force` on `stone edit`, a `force` field on the PATCH request, and a web flow that shows the gaps and offers the override. Not planned yet.
