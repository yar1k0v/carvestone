## Description

Agents find Terraform resources, data sources and modules with `stone code find`, and `stone code uses <module file>` lists the module blocks whose local `source` points at it. Parsed with `hcl-edit` (ADR-22).

## Plan

1. `Cargo.toml`: add `hcl-edit = "0.10"` under `[workspace.dependencies]`; `crates/graph/Cargo.toml`: `hcl-edit.workspace = true`. Docs: https://docs.rs/hcl-edit/0.10.0/hcl_edit/ (`parser::parse_body`, `structure::Body`, `structure::Block` with `ident`, `labels`, `body`; the `Span` trait's `span()` gives a byte range).
2. `crates/graph/src/facts.rs#Lang`: add `Terraform`; `as_str` returns `"terraform"`; `lang_of` maps `tf` to it (not `tfvars`: values, no declarations).
3. `crates/graph/src/terraform.rs` (new) with `extract_terraform(path, src) -> FileFacts` (new):
   - First decl is the `DeclKind::File` decl, built like `crates/graph/src/dart.rs#extract_dart`.
   - `parse_body` the text. On error, keep only the file decl and add one `Warning` at the error's line (count `\n` before its byte offset, or line 1).
   - Top-level `resource "T" "N"` becomes `DeclKind::Type` with name `T.N`; `data "T" "N"` becomes `DeclKind::Type` with name `data.T.N`; `module "N"` becomes `DeclKind::Module` with name `module.N`. `qname` is `<dir>#<name>`, `<dir>` the file's folder (`.` at the repo root), since Terraform addresses are unique per module folder. `parent: Some(0)`. `signature` is the block header line as written, trimmed. Lines from the block span: line = 1 + count of `\n` before the offset.
   - A module's `source` attribute with a string value adds a `RefSite` of `RefKind::Imports`, `name` the value as written, `scope` the module decl, `line` the attribute's line.
   - Other block types (`variable`, `output`, `locals`, `provider`, `terraform`) add nothing.
4. `crates/graph/src/lib.rs#extract`: add `Lang::Terraform => terraform::extract_terraform(path, src)` and `mod terraform;`.
5. `crates/graph/src/resolve_terraform.rs` (new) with `TerraformResolver` (new), returned by `crates/graph/src/resolve.rs#resolver_for` and listed in `LANGS`. An Imports site whose name starts with `./` or `../` joins to the module's folder and normalizes `.` and `..` segments; it gives one exact edge to the File decl of each Terraform file directly in that folder. No such file, or any other source (registry, git, URL), gives `dst: None` with the name as written.
6. `crates/engine/src/code_index.rs`: `governing_kinds(Lang::Terraform)` returns `&[]`; add `Lang::Terraform` to `lang_from`. Bump `crates/graph/src/lib.rs#CODE_GRAPH_VERSION` by one.
7. Seam: block-to-decl mapping and the parse-error path in `extract_terraform`. It catches resource, data and module names and their lines; it misses blocks nested inside modules. Test choice: add (private code with real logic). `crates/graph/src/terraform.rs` gets `#[cfg(test)] mod tests` with one table test: a file with one resource, one data block and one module gives the three names with their lines; a file with an unclosed `{` gives only the file decl and one warning.
8. Seam: a resource and a module source across folders. Test choice: patch, in `crates/engine/tests/features/code_graph.rs#each_language_finds_a_definition_and_its_call_site_in_another_file`.
   - Add a row `"terraform"` (raise the row count). Files: `src/infra/net/main.tf` holds `resource "aws_vpc" "main" {\n  cidr_block = "10.0.0.0/16"\n}\n`; `src/infra/net/outputs.tf` holds `resource "aws_subnet" "a" {\n  vpc_id = aws_vpc.main.id\n}\n`. Name `aws_vpc.main`. Find expects one `type exact` hit at `src/infra/net/main.tf:L1-3`; uses expects no hits (resource references are out of scope, ADR-22).
   - After the loop, add one block: a store with those two files plus `src/infra/main.tf` holding `module "net" {\n  source = "./net"\n}\n`. `uses` of `src/infra/net/main.tf` expects one `imports exact` hit from `src/infra#module.net` at line 2.
   - Copy the full line text from the first red run, then check every field by hand against the fixture.
