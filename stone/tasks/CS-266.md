## Description

Agents and the owner can delete one section of an item with `stone edit <id> --remove-section <name>`, and web clients with `remove_section` on `PATCH /api/items/{id}`. Today `--section` only replaces or adds, so removing a plan meant deleting and recreating the task. The MCP server has no edit tool (`crates/mcp/src/lib.rs` sends changes to the CLI), so it does not change.
