## Description

First build step of ADR-13. A doc may say level: lld (or hld) in its frontmatter, and stone check rejects any other value. stone arch hld prints the high-level design of the product: system and containers with their descriptions, how they connect (the uses between containers and the Rel lines of the C4 diagrams), and the docs marked hld. stone arch lld <container> prints the low-level design of one container: the service view that stone code explain gives (modules, entry points, packages, libraries) under an LLD heading, plus the docs marked lld that link the container, each with the start point it names. Both print only what is asked for and say when a section is empty. The agent guide names both commands and stays within its line limit.

## Acceptance criteria

- [x] stone check rejects a level value other than hld or lld and names the allowed ones
- [x] stone arch hld lists systems and containers, how they connect, and docs marked hld
- [x] stone arch lld <container> prints the service view and the docs marked lld that link it; an unknown container names the containers
- [x] The agent guide names both commands and stays within its limits
- [x] cargo test --workspace and cargo clippy --workspace --all-targets -- -D warnings

## Outcome

A doc can now say level: hld or level: lld, and stone check rejects any other value and names the two allowed ones. stone arch hld prints the systems and containers with their descriptions, how they connect (the uses between them, with the phrase each one carries, and the Rel lines of the Context and Container diagrams as written), and the docs marked hld; each empty section says so in one line. stone arch lld <container> prints the service view that stone code explain gives under an LLD heading, plus the docs marked lld that link the container, each with the path#Symbol start point it names (from the doc's entry field, else the first path#Symbol code span in its body). An unknown container, or one that is not a container, gets a sentence that names the containers. Both commands take --json. The agent guide and the agent block name both commands, and the overview stays within 25 lines.
