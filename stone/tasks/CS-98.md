## Description

When an indexer fails in one repo, code native stops that language for every repo. It should go on with the other repos and report the failed one. Seen on Freightline: scip-python failed in freightline-admin and notifier, watcher and processing-svc were never indexed.

## Acceptance criteria

- [x] When an indexer fails in one directory, the pass goes on with the other directories, keeps their indexes and reports each failed directory with the reason: cargo test -p carvestone-engine --test code_native
- [x] A failed directory is run again on the next pass while the others are read from their kept indexes: cargo test -p carvestone-engine --test code_native
- [x] cargo clippy --workspace --all-targets -- -D warnings

## Outcome

Code native goes on with the other directories and repos when an indexer fails in one. The failed directory is listed with the reason, the directories that worked keep their indexes, and the next pass runs only the failed one again.
